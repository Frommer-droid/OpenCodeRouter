# История изменений

## Версия 0.3.4 (2026-10-24)

*Россия исключена из доступных локаций OpenCode Router.*

### 🐛 Исправления

- Российские локации скрыты из списка и меню, пропускаются при полном сканировании, автоматическом выборе и поиске другого IP. Ручные команды `use` и `test` также отклоняют такие узлы.
- Исключение действует по флагу 🇷🇺, названиям страны и отдельным кодам RU/RUS независимо от пользовательского списка `excludedNodes`. Проверка геолокации IP не выполняется.

### 🛡️ Безопасность

- Сборка проверяет происхождение native-библиотек до замены MSVC runtime и после неё: посторонняя DLL останавливает сборку.
- Сборочная зависимость setuptools обновлена до 84.1.0 с исправлением обработки путей Windows при установке wheel.

### ✅ Проверки

- Добавлены проверки вариантов названия России, сохранения остальных стран, пропуска запрещённых узлов и отказа ручного выбора.

## Версия 0.3.3 (2026-10-17)

*Узлы и полный тест идут по русскому алфавиту.*

### 🐛 Исправления

- При запуске таблица сортируется по столбцу «Узел» по возрастанию русского названия, без учёта флага страны. Раньше исходный порядок определяла задержка.
- Проверка «Все узлы» начинается с первой разрешённой локации по русскому алфавиту, независимо от порядка подписки и текущего маршрута.

### ✅ Проверки

- Проверены начальный указатель сортировки, порядок после обновления таблицы, выделение текущего маршрута, исключение запрещённых узлов и восстановление исходной локации после полного теста.
- Ручная сортировка и последовательная смена IP сохраняют своё поведение. При запуске по-прежнему проверяется только текущий маршрут.

## Версия 0.3.2 (2026-10-17)

*Понятный выбор локаций OpenCode и обновлённая Windows-поставка.*

### 🐛 Исправления

- Добавлен пример Global Script для выбора направлений со ⭐ или 🚀. Вложенные группы стран сохраняются целиком, без раскрытия до внутренних серверов с техническими именами.
- Папка установки определяется на компьютере пользователя: `D:\Apps\OpenCodeRouter` при наличии диска D, иначе `C:\Apps\OpenCodeRouter`.

### 🛠 Улучшения

- Унифицированы командные файлы запуска из исходников; обновлены инструкции интеграции.
- Временные материалы сборки вынесены отдельно от исходников; сохраняются аудит DLL и рабочие файлы проверки.
- Из распространяемого отчёта сборки исключены локальные пути разработчика.

### 📚 Документация

- Уточнено, что правило для `opencode.exe` не зависит от папки установки или версии OpenCode. Обновление Global Script выполняется отдельно от установки Router.

## Версия 0.3.1 (2026-09-23)

*Совместимость с обновлённым Clash Verge Rev для OpenCode TUI.*

### 🐛 Исправления

- Router определяет действующее имя локального named pipe из конфигурации Clash Verge Rev при каждом запросе к контроллеру. После смены режима ядра или обновления Clash ручная правка `controllerPipe` больше не требуется.
- Пользовательские имена pipe остаются неизменными; удалённые пути к pipe отклоняются.

### ⚡ Улучшения

- Обновлена документация установки и опубликованного репозитория. Маршрутизация по-прежнему привязана к `opencode.exe` для терминального OpenCode.

## Версия 0.3.0 (2026-09-09)

*Автоконтроль маршрута, последовательная смена IP и мгновенное переподключение OpenCode.*

### ✨ Новые возможности

- Кнопка «Все узлы» последовательно измеряет доступность, внешний IPv4 и задержку каждого разрешённого узла.
- После полного теста исходный маршрут восстанавливается даже при ошибке; автоматического переключения не происходит.
- Таблица сразу обновляется полным набором свежих результатов, включая недоступные локации.
- Программа каждые 5 минут тихо проверяет текущий маршрут и при отказе последовательно переключается на первую рабочую локацию по русскому алфавиту.
- Windows-уведомления сообщают о запуске, начале и результате автоматического переключения, отсутствии рабочих локаций и потере связи с Clash.

### ⚡ Улучшения

- Названия локаций в таблице и последовательный перебор используют русскую часть названия страны, независимо от флага и кода в начале строки.
- После смены локации старые соединения `opencode.exe` с группой OpenCode Router закрываются точечно, поэтому новый трафик сразу идёт через выбранный сервер без перезапуска OpenCode.

## Версия 0.2.0 (2026-09-08)

*Первый полноценный Windows-релиз OpenCode Router с управлением из системного лотка.*

### ✨ Новые возможности

- Закрытие окна теперь сворачивает приложение в системный лоток.
- Контекстное меню иконки лотка содержит команды «Показать» и «Выход».
- Клик или двойной клик по иконке возвращает окно на экран.
- Добавлены сортировка всех столбцов, маркировка текущего маршрута и ненавязчивая подсветка недоступных узлов.
- Подготовлены воспроизводимая PyInstaller-сборка, portable-развёртывание и Windows-установщик.

### 🐛 Исправления

- Исключён запуск с неверным глобальным Python вместо проектной `.venv`.
- Устранены повреждение кириллицы/emoji в выводе PowerShell и вспышка чужой темы при старте.
- Добавлена фильтрация исключённых узлов в ручном и автоматическом выборе.

### ⚡ Улучшения

- Интерфейс приведён к One Dark Pro и получил единый комплект SVG/ICO-иконок.
- Сборка проверяет происхождение native DLL по принципу fail-closed и фиксирует результат аудита.
- Поставка не содержит локальный controller secret, пользовательские настройки, логи или кэш.
